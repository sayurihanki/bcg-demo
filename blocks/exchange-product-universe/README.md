# Exchange Product Universe Block

## Overview

Renders eight BCG X product cards, category counts and filters, a configurable pilot builder, and the open-source strip.

## Integration

- One authored row represents a BCG X product: identity, copy, metric, and links.
- Pilot options are 8/12/16 weeks, 1–12 markets, and 25/50/100 seats.
- Configured items replace an existing product through the shared workspace module.

## Error Handling

Market values are clamped at both limits and all commercial terms remain custom-quote requests.
